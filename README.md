Bluetooth-Based Smart Wireless Toll Barrier Using LPC2129

📌 Project Overview
This project aims to automate toll barrier operations using Bluetooth wireless communication and the LPC2129 ARM7 microcontroller. It enables wireless vehicle access control and automatic barrier opening and closing, reducing manual intervention and waiting time.

🛠️ Hardware Requirements
LPC2129 ARM7 Microcontroller
Bluetooth Module (HC-05/HC-06)
DC Motor / Servo Motor
Motor Driver
Power Supply

💻 Software Requirements
  ->Embedded C
  ->Keil µVision IDE
  ->Flash Magic
  
⚙️ Working Principle
Bluetooth establishes wireless communication.
Vehicle information is transmitted to the controller.
LPC2129 receives and processes the data through UART.
If the information is valid, the motor is activated.
The toll barrier opens and closes automatically.

✨ Key Features
Wireless Bluetooth communication.
Automatic toll barrier control.
LPC2129 ARM7-based operation.
UART serial communication.
Reduced manual intervention.
